# MDLM模型 Levenshtein分析对比报告

## 问题诊断

**原生分析的问题**: 使用了错误的文件格式进行对比

- ❌ 原生分析使用: `.out.final` (编码格式: `0W1B1H0L0J0N0`)
- ✅ 正确分析使用: `.out` (数字序列格式: `0 1 1 0 0 0...`)

由于两种文件格式完全不同，导致原生分析的Levenshtein距离计算结果严重失真。

## 结果对比

| 指标 | 原生分析（错误） | 正确分析 | 差异 |
|-----|----------------|---------|------|
| 总编辑距离 | 21,420 | 11,925 | -44.3% |
| 平均编辑距离 | 1.97 | 1.10 | -44.2% |
| 归一化距离 | ~0.0352 | 0.0294 | -16.5% |
| 字符级准确率 | 96.48% | **97.05%** | +0.57pp |
| 序列级准确率 | 45.01% | **45.01%** | 相同 |
| 最大编辑距离 | > 10 | 10 | 改善 |
| dist>10 样本数 | 161 (1.5%) | **0 (0.0%)** | 完全消除 |

## 关键发现

### 1. 性能实际更好
正确分析显示模型性能比原生分析好得多：
- **平均编辑距离降低44%** (1.97 → 1.10)
- **字符级准确率达到97.05%**
- **没有超过10个编辑距离的困难样本**

### 2. 编辑距离分布

**原生分析（错误）**：
```
dist=0:     4,892 (45.0%)
dist 1-5:   4,818 (44.3%)
dist 6-10:    998 (9.2%)
dist>10:      161 (1.5%)  ← 不应存在
```

**正确分析**：
```
dist=0:     4,892 (45.0%)
dist 1-5:   5,857 (53.9%)  ← 提升9.6pp
dist 6-10:    120 (1.1%)   ← 减少8.1pp
dist>10:        0 (0.0%)   ← 完全消除
```

### 3. 中位数表现优异
- 中位数编辑距离: **1**
- 意味着50%的序列编辑距离≤1
- 绝大部分预测非常接近金标准

## 模型综合评估

### 验证集表现
- 最佳验证准确率: **96.85%** (epoch 46)

### 测试集表现
- 字符级准确率: **97.05%**
- 序列级准确率: **45.01%**
- 平均编辑距离: **1.10**
- 归一化编辑距离: **0.0294** (每字符平均误差2.94%)

### 距离分布特征
- **98.9%的序列**编辑距离≤5
- **45.0%的序列**完美匹配
- **0%的序列**编辑距离>10

## 结论

1. **原生分析结果不可信**：由于文件格式错误，严重低估了模型性能

2. **实际性能优异**：
   - 97.05%的字符级准确率
   - 平均每个序列仅有1.1个错误
   - 没有严重错误的样本（dist>10）

3. **模型可用性高**：
   - 绝大部分预测非常准确
   - 错误主要集中在小范围内（1-5个字符）
   - 适合实际应用部署
