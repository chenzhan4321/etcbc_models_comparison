## 错误模式分析

### 小距离错误 (dist 1-5)

典型错误模式：
- **标记扩展**: `MR>/` → `MR(>/~>` (增加了额外的标记)
- **标记简化**: 预测缺少某些特殊标记
- **长度差异**: 通常相差3-4个字符

示例（行5）:
```
Target: L-J D-B->JN> JWTRN/~> !>!CR(J&>[ HJDJN PQD[-NJ MR>/
Pred:   L-J D-B->JN> JWTRN/~> !>!CR(J&>[ HJDJN PQD[-NJ MR(>/~>
距离: 3 (长度差异: 51→54)
```

### 大距离错误 (dist>10)

影响因素：
- **复杂标记组合**: 如 `!!CRJ[` vs `CRJ[:d`
- **特殊符号处理**: 如 `!M!](>]D(W&JB[/` vs `MDJB=[/:d`
- **长度显著差异**: 通常相差5-10个字符

示例（行19）:
```
Target (68字符): D-B-J<QWB/ !!CRJ[ W-!!@>(T&C@(C&TRR=[(J:d B->JSRJL/ MN QDM/ <LM/(J~>
Pred   (60字符): D-B-J<QWB/ CRJ[:d W-@>(T&C@(C&TRR=[ B->JSRJL/ MN QDM/ <LM/~>
距离: 12 (长度差异: 68→60)
```

### 错误原因分析

1. **特殊标记识别**: 模型在处理 `!!` 等双重标记时可能不够准确
2. **标记组合**: 复杂的标记组合（如 `(J:d`, `[/:d`）容易混淆
3. **序列长度**: 模型倾向于生成稍短的序列
